# obs-tuner

Утилита для настройки OBS под стрим на Twitch: подбор кодировщика и битрейта под твоё железо, цепочка фильтров качества и разбор лога на дропы кадров.

Node.js, без сборки. Зависимость — только `ws` (нужна для применения фильтров в запущенной OBS).

## Установка

```
npm install
```

## Быстрый старт

```
node src/cli.js all
```

Покажет GPU, рекомендованный кодировщик, битрейт под выбранное разрешение и цепочку фильтров. Ничего не меняет.

## Команды

| Команда | Что делает |
| --- | --- |
| `doctor` | GPU, драйвер, кодировщик, профили OBS, наличие obs-websocket |
| `plan` | рекомендованные настройки энкодера/битрейта (без записи) |
| `profile --apply` | записывает настройки в профиль OBS (`basic.ini`, с бэкапом) |
| `filters --apply` | добавляет и настраивает фильтры в запущенной OBS |
| `check` | разбор последнего лога OBS: пропущенные кадры, ошибки энкодера, сеть |
| `all` | doctor + plan + filters одним прогоном |

### Примеры

```
node src/cli.js all --res 1920x1080 --fps 60
node src/cli.js profile --apply --profile "Twitch 1080p60"
node src/cli.js profile --apply --gpu nvenc --res 2560x1440 --capture 2560x1440
node src/cli.js filters --target "Сцена" --capture 2560x1440 --game
node src/cli.js filters --apply --target "Сцена" --sharpen 0.2
node src/cli.js check --log "%APPDATA%\obs-studio\logs\2026-09-27-12-00-00.txt"
```

`node src/cli.js help` — полный список флагов.

## Важно

- `profile --apply` требует закрытой OBS: при закрытии OBS перезаписывает `basic.ini` своими значениями. Перед записью создаётся `.bak`.
- `filters --apply` требует включённого obs-websocket: OBS -> Сервис -> Веб-сервер obs-websocket, порт 4455. С аутентификацией добавь `--password`.
- Трансляция для другого сервиса: `--software youtu.be` поднимает лимит битрейта, но ключи OBS-профиля остаются те же.

## Что даёт качество картинки (по убыванию эффекта)

1. Аппаратный кодировщик (NVENC / AMF / QSV) и стабильные 60 FPS без пропусков.
2. Битрейт 6000 kbps для 1080p60, CBR, интервал ключевых кадров 2 секунды.
3. Захват в нативном разрешении: холст = разрешение трансляции, масштабирование на GPU, NV12 8 бит 4:2:0.
4. Никогда не растягивать 720p до 1080p — фильтры это не лечат.
5. Фильтры: Lanczos при даунскейле, лёгкая резкость (0.1-0.15), цветокоррекция.

Проверять результат локальной записью (mkv, CRF 18) — так видно качество до сжатия Twitch.
